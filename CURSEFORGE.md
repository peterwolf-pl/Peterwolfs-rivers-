# Peterwolf's Rivers

**Real river currents. Real navigation challenges.**

Peterwolf's Rivers is an upcoming hydrodynamics mod for **Minecraft Java 26.3 (Fabric)**. It aims to replace simplistic river movement with a dedicated water simulation built for realistic inland navigation.

### Planned features
- **Dynamic currents:** different water speeds based on river depth, width, bends, and obstacles.
- **Eddies and turbulence:** swirling currents around banks, bridge pillars, and narrow passages.
- **Custom river water and biome:** a separate river-fluid system rather than vanilla water flow.
- **Navigable waterways:** wide rivers, branching channels, canals, gorges, and rapids.
- **Working hydraulic structures:** locks, gates, and weirs that affect water levels and flow.
- **Wind & Sails integration:** combine river currents with wind-driven sailing physics.
- **River-inspired environments:** designed with waterways such as the Odra in Wrocław in mind.

**Development status:** Early development. Features above describe the project roadmap and are not yet available in a public release.

**Target:** Minecraft Java 26.3 | Fabric | Java 25.
