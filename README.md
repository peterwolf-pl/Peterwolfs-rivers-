# Peterwolf's Rivers

**A planned hydrodynamics and inland navigation mod for Minecraft Java 26.3 (Fabric).**

Peterwolf's Rivers aims to introduce independent river-water physics, varied currents, turbulence around obstacles, wide navigable channels, river locks, weirs, and integration with Peterwolf's Wind & Sails.

> **Status: early development.** These capabilities are project goals, not yet released features.

The ready-to-paste CurseForge description is in `CURSEFORGE.md`.
